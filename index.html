Data Science & Visualization Projects

CO2 Emissions & Economics Explorer

Python, D3.js, Flask, Data Visualization
GitHub

An interactive dashboard exploring how CO2 emissions, economic development, and renewable energy adoption relate across 190+ countries from 2010 to 2023.

  • Integrated 5 global datasets from Our World in Data and World Bank (emissions, GDP, renewables, energy use, population) behind a Flask REST API serving cleaned time-series data
  • Built five linked D3.js views: a choropleth map, a top-emitters bar chart, a brushable trend line, a parallel coordinates plot, and a radar chart scoring environmental performance, all cross-filtering together

Predicting Student Summary Quality

Python, pandas, scikit-learn, NLTK, textstat

A regression project on the CommonLit "Evaluate Student Summaries" dataset, predicting how well a student's summary captures the content and wording of the prompt it's based on.

  • Joined summaries with their source prompts in pandas, then engineered handcrafted NLP features with NLTK and textstat, including word counts, prompt overlap, and a Flesch-Kincaid readability score
  • Found content and wording scores strongly correlated (r ≈ 0.75), and compared word frequencies between high- and low-scoring essays
  • Modeled both scores in scikit-learn, improving from a baseline Linear Regression to a 100-tree Random Forest, which performed best (MSE 0.205 content / 0.355 wording)

Stock Price Movement Prediction

Systems & Security Projects

Kernel-Level Security Enforcement

C, ptrace, eBPF, LSM, BPF Maps

Multi-layer security enforcement system using both userspace (ptrace) and kernel-level (eBPF/LSM) mechanisms for transparent application sandboxing and policy enforcement.

  • Built a ptrace-based sandbox (safex) that confines file access for any application by intercepting its system calls: it blocks reads of blocklisted files and silently redirects writes to temporary copies (via mkstemp) so the real files are never touched, with the same protection carried over to any child processes it spawns
  • Developed an eBPF/LSM policy suite (eGuard) enforcing kernel-level rules: denying file creation in a protected directory, blocking execution of a specific binary, and blocking outbound connections to a specific IP

Binary Exploitation & Memory Corruption

C, x86-64 Assembly, GDB, objdump

A hands-on exploit-development project: breaking into a C server with every common protection turned on (ASLR, PIE, stack canaries), using just one information leak to work around all of them.

  • Bypassed the login check without any leak, by corrupting a pointer so the program ended up comparing a password against itself
  • Used the leak to locate and hijack a hidden function in the binary, eventually running injected shellcode to take full control of execution
  • Pulled off the same attack again with zero leaks, by brute-forcing the stack canary byte by byte instead

Publications

Enhanced File System Testing through Input and Output Coverage

Y. Liu, G. Kuenning, M.K. Parvez, et al.

ACM SYSTOR 2025, pp. 151–166

View Paper

  • Showed that code coverage alone is a weak predictor of file system test effectiveness, since many real bugs sit in already-covered code and still go undetected
  • Introduced input and output coverage, metrics based on which system call arguments and return values are exercised, as a better signal for what testing actually catches
  • Built the IOCov framework to compute these metrics with minimal overhead, and used it to extend the CrashMonkey testing tool into CM-IOCov
  • CM-IOCov found 2.1x to 12.9x more crash-consistency bugs than CrashMonkey alone

An end-to-end authentication mechanism for wireless body area networks

M. Jahan, F.T. Zohra, M.K. Parvez, et al.

Smart Health (2023): 100413

View Paper

  • Proposed an end-to-end authentication and session key agreement scheme between sensors and medical experts that treats the patient's phone as only semi-trusted
  • Addressed a gap in existing WBAN (Wireless Body Area Network) authentication schemes, which typically assume the patient's mobile phone is fully trusted even though it can be stolen or compromised by malware
  • Validated the scheme with a formal security analysis (BAN logic) and an informal analysis, both showing robustness against well-known attacks
  • Evaluated it on real deployment data and NS-3 simulation, finding comparable computation, communication, and energy overhead to state-of-the-art methods with no loss in network performance

A secure and lightweight user authentication mechanism for wireless body area network

M.K. Parvez, F.T. Zohra, M. Jahan

NSysS 2019, ACM, pp. 139–143

View Paper

  • Proposed a lightweight user authentication and session-key agreement protocol between sensor nodes and medical experts, covering both communication patterns in WBAN: sensor-to-mobile-device and mobile-device-to-application-provider
  • Addressed a gap in prior work, where no end-to-end authentication mechanism existed between sensor nodes and medical experts, and separate protocols for the two communication patterns were hard to integrate due to their differing nature
  • Showed through security analysis that the protocol preserves the required security properties
