About Me

I am a graduate student pursuing an M.S. in Computer Science at Stony Brook University (expected graduation: December 2026). I build LLM agent systems and retrieval-augmented pipelines in Python, including multi-agent LangGraph pipelines with ReAct-style tool calling and RAG chatbots backed by vector search (Weaviate, Gemini embeddings), and use agentic coding tools such as Claude Code in daily development. I also bring deep expertise in Linux kernel development, systems programming, and security, spanning storage subsystems, memory management, and process isolation.

My research has been published at ACM SYSTOR 2025, focusing on crash-consistency testing frameworks for file systems. I have hands-on experience developing Linux kernel modules, building sandboxing and confinement systems using namespaces, cgroups, ptrace, and eBPF/LSM hooks, and working with clustered file systems and NUMA-based architectures.

With over 3 years of professional experience as a Software Quality Assurance Engineer and prior teaching assistant roles at Stony Brook University, I combine theoretical knowledge with practical system-level programming skills. I'm proficient in C, C++, and Python, and experienced in building automated testing and monitoring infrastructure.

Kernel-Level Security Enforcement

C, ptrace, eBPF, LSM, BPF Maps

Multi-layer security enforcement system using both userspace (ptrace) and kernel-level (eBPF/LSM) mechanisms for transparent application sandboxing and policy enforcement.

  • Built ptrace-based sandbox (safex) transparently mediating file access for unmodified applications: denied reads from blocklist (~/.safenoread), redirected writes to temporary copies via mkstemp (avoiding race/symlink attacks)
  • Implemented automatic child process tracing handling descendant processes spawned by sandboxed applications
  • Developed eBPF/LSM policy suite (eGuard) enforcing kernel-level security: deny file creation in protected directories, block specific binary execution (/bin/nc), block outbound connections to specific IPs
  • Used BPF maps (in-kernel key-value stores) streaming structured events (timestamp, syscall, UID, PID, target path/IP, decision) to userspace logger with minimal context-switch overhead
  • Handled multiple syscall variants (open, openat, etc.) identified via strace analysis before implementing interception logic

Control-Flow Integrity & ROP Detection

  • Logged violations into C++ unordered_map with per-address counts; resolved addresses to function/library names using Pin's symbol API and /proc/pid/maps
  • Extended to be thread-safe with per-thread shadow stacks and independent mismatch reporting for multi-threaded applications
  • Actively detected ROP-style control-flow hijacking attacks in real time, including validation against exploit payloads from binary exploitation assignments
  • Characterized benign recurring mismatches (setjmp/longjmp, library exception handling) versus genuine attacks across simple and complex GUI applications
